Hai, panggil saja saya **Kibo**! 👋

Saya adalah seorang pengembang perangkat lunak yang berfokus pada pengembangan _backend architecture_ dan web application. Dengan keahlian utama di **C# (.NET)**, saya terbiasa membangun sistem yang robust, scalable, dan mudah untuk dipelihara.
